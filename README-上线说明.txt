# 中美远程公证服务｜创业获客版

## 已包含
- 中文首页
- 中英文切换（静态前端）
- 服务项目
- Apostille / Authentication 专题区
- 办理流程
- FAQ
- 电话 / Email CTA
- 在线咨询表单
- 文件选择框
- SEO title / description / Open Graph
- Schema.org ProfessionalService 基础结构
- 手机端自适应
- 法律/服务范围免责声明

## 上线前必须替换
1. `https://YOUR-DOMAIN.example` → 正式域名
2. 如有微信二维码，加入二维码图片并链接到微信咨询区
3. 将演示版 mailto 表单换成真正的安全表单服务/后端
4. 如使用 Google Business Profile，请保持网站名称、电话、服务区域等信息一致
5. 根据实际执业资格和业务范围核对“注册公证员/注册公证人”等头衔表述

## 推荐部署
- Vercel：适合静态网站，绑定自有域名简单
- Netlify：适合静态网站和表单
- Cloudflare Pages：适合低成本静态部署

## 合规提示
网站没有把“人在美国即可视频完成所有加州公证”作为宣传语。加州现行规则仍要求当事人亲自出现在公证人面前；SB 696 的相关远程在线公证条款尚未生效。
